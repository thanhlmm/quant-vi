# Giáo trình Quant trực quan (tiếng Việt)

21 bài, từ định lý Bayes đến tạo lập thị trường: ghi chú tiếng Việt, công thức, ví dụ có lời giải, lưu ý phỏng vấn và mô hình tương tác (canvas, xoay 3D).

Lộ trình bám theo mục lục của [hft.md](https://hft.md/learn/). Ghi chú và toàn bộ mô hình tương tác được viết mới; mỗi bài liên kết tới bài gốc. Tài liệu giáo dục, không phải khuyến nghị đầu tư.

Xây dựng: `bun build.ts` ghép `shell.html` + `parts/NN.html` thành `index.html`.
